# «Тёплый дом» — проектная работа 1 спринта

Кейс компании «Тёплый дом» курса «Архитектура программного обеспечения»
(Яндекс Практикум Казахстан): переход от монолита к микросервисной
SaaS-экосистеме умного дома.

Решение выполнено на .NET 10 / C#.

**Работа ведётся в ветке [`warmhouse`](../../tree/warmhouse).**
Там же — ответы на задания 1–5 в файле `Project_template.md`, исходный код,
диаграммы C4 и ER, документация API и docker-compose для запуска.
